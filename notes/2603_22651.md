# Benchmarking Multi-Agent LLM Architectures for Financial Document Processing: A Comparative Study of Orchestration Patterns, Cost-Accuracy Tradeoffs and Production Scaling Strategies

- **ID:** arXiv:2603.22651 (v1, 24 Mar 2026) — verified from https://arxiv.org/html/2603.22651v1 (full text)
- **Authors:** Siddhant Kulkarni, Yukta Kulkarni
- **Status:** INCLUDE — category: adjacent (disclosure document extraction / analyst band)

## Summary
Systematic benchmark of four multi-agent LLM orchestration architectures (sequential pipeline, parallel fan-out with merge, hierarchical supervisor-worker, reflexive self-correcting loop) for structured field extraction from SEC filings. Evaluates 5 LLMs (GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro, Llama 3 70B, Mixtral 8x22B) x 4 architectures on 10,000 EDGAR filings, measuring F1, document accuracy, latency, cost per document, and token efficiency; includes ablations (semantic caching, model routing, adaptive retries), a 1K-100K docs/day scaling analysis, and a 12-mode failure taxonomy.

## Tasks
- 25 extraction field types in 3 domains (Sec IV-B): Financial Metrics (10 fields: revenue, net income, assets, liabilities, equity, OCF, capex, EPS basic/diluted, D/E), Governance (8 fields), Executive Compensation (7 fields).
- 3 filing types: 10-K (4,000), 10-Q (4,000), 8-K (2,000) = 10,000 documents (Table I), FY2021-2024, 11 GICS sectors.
- 500 experimental configurations claimed ("25 field types, five models and four architectures yielding 500 distinct experimental configurations", Sec I-B); 200,000 document-level evaluations (Sec IV-E).

## Eval method
Exact-match style: field-level micro-F1 with "exact match (for categorical fields) and ±2% tolerance (for numerical fields)" (Sec IV-D); document-level strict/relaxed accuracy; latency p50/p95; cost per document; token efficiency. No LLM-judge. Ground truth: XBRL pre-annotation (~60% of financial metric fields) + 12 annotators with CFA/CPA credentials, Cohen's kappa = 0.91, senior-analyst adjudication (Sec IV-B).

## Data realism
Real — actual SEC EDGAR filings (10-K/10-Q/8-K), converted from HTML/XBRL to text; oversampled complex filers (conglomerates, financials, REITs) (Sec IV-A).

## Agent scope
Multi-agent (4 orchestration patterns composed from atomic agents: document parser, field extractor, table analyzer, cross-reference resolver, confidence scorer, output formatter; LangGraph v0.2). Extraction workflow, not long-horizon business process.

## Key numbers (quoted)
- Abstract: "We find that reflexive architectures achieve the highest field-level F1 (0.943) but at 2.3x the cost of sequential baselines, while hierarchical architectures occupy the most favorable position on the cost-accuracy Pareto frontier (F1 0.921 at 1.4x cost)."
- Sec I-B Contributions: "hierarchical architectures provide the best cost-accuracy tradeoff for production financial document processing, achieving 97.7% of reflexive architecture accuracy at 60.9% of the cost."
- Sec I-B / Abstract: "hybrid configurations can recover 89% of the reflexive architecture's accuracy gains at only 1.15x baseline cost."
- Table III (Sec V-A): Sequential F1 = 0.897 (GPT-4o), 0.903 (Claude 3.5S), 0.881 (Gemini 1.5P), 0.834 (Llama3 70B), 0.812 (Mixtral 8x22B); strict doc accuracy 0.453-0.648 for sequential.
