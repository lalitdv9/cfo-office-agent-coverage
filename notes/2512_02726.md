# AuditCopilot: Leveraging LLMs for Fraud Detection in Double-Entry Bookkeeping

## Summary
Prompt-engineered (no weight updates) open-weight LLMs as unsupervised anomaly/fraud detectors over journal entries in double-entry bookkeeping, replacing/augmenting rule-based Journal Entry Tests (JETs). Prompt = system guidelines + dataset summary statistics (amount percentiles, user frequencies) + Isolation Forest decision as a hint; per-posting-ID JSON record in, strict JSON {anomaly 0/1, explanation} out. Explicitly framed as auditor decision support ("AI-augmented auditing, where human auditors collaborate with foundation models").

## Tasks
- Binary anomaly classification per posting ID (JE grouping) + natural-language rationale, on tax-related ledger data.
- Datasets: (1) synthetic JE dataset (pub15550; medium-sized-enterprise bookkeeping sim) — 5,000 posting IDs sampled, 1% anomaly rate (50 anomalous); (2) real-world anonymized general ledger from industry partner — anonymization broke posting-ID linkage, so treated transaction-level; pseudo-labels from client-verified JET rules (~6% anomaly rate).

## Eval method
Precision/recall/F1/TP/FP/FN/TN vs (a) simulator ground truth (synthetic) and (b) JET-derived pseudo-labels verified by the client (real data — note circularity risk: "Pseudo-labels based on JETs may inherit rule-based biases", Limitations). Baselines: rule-based JET, Isolation Forest. Prompt ablations (w/o IF hint; w/o stats+IF).

## Data realism
Mixed: one real anonymized tax-related ledger (industry partner; no true fraud labels) + one synthetic benchmark. Authors: "external validity remains to be demonstrated with larger, multi-source datasets and independent audit labels."

## Agent scope
Non-agentic: single LLM call per record with engineered prompt + classical-ML (Isolation Forest) signal fusion; no tool use, no multi-step workflow. Open-weight models preferred for privacy (LLaMA 3.1 8B, Gemma 2B/7B, Mistral 8B/22B) + GPT-5-mini comparison.

## Key numbers (quoted from Tables 1-2)
- Synthetic: JET P=0.53/R=0.90/F1=0.50 (FP=942); Isolation Forest F1=0.68 (FP=169); **Mistral-8B best F1=0.94** (P=0.90, R=0.98, FP=12); Gemma-7B R=0.99 FP=68; GPT-5-mini perfect recall but FP=466.
- Anonymized real ledger: Isolation Forest F1=0.46; **Gemma-7B best F1=0.83** (P=0.89, FP=32); ablations: removing IF hint → Gemma-7B FP 32→1973; removing stats → Gemma-2B FN 6→306. "Statistics are key for recall, while Isolation Forests are crucial for precision."

## Leaf cells (justified)
- **1.1:P** journal entries — the system consumes JE/ledger records for audit-side anomaly detection; partial because it does not prepare/post JEs (audit consumption, not R2R execution). Primary placement is the audit category, not a core R2R row.

## Relevance
First-claim: "we provide the first evidence that LLMs can be applied to tax-related ledger data." Sits in the audit band next to JE-testing/audit-copilot work (cf. corpus audit_overlap.md); useful eval-methodology contrast: pseudo-labeling by JET rules as ground truth is a documented weak point.
