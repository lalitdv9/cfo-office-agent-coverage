- **ID:** arXiv:2508.00828 (fetched HTML v1). Dataset CC BY 4.0 (DOI 10.57967/hf/5514); harness MIT (Zenodo 10.5281/zenodo.15428823); github.com/vals-ai/finance-agent; leaderboard vals.ai

- **Status:** FULL TEXT fetched 2026-07-16 from https://arxiv.org/html/2508.00828v1 (body + Appendices A–E read). Band = ADJACENT per Checkpoint-1 human ruling (investor-side analyst-research benchmark).

## Summary
537 expert-authored financial research questions over recent (post-2024) SEC filings, in a 9-category taxonomy developed with 7 finance-industry experts (banks, hedge funds, PE; 2-3+ yrs at bulge-bracket firms). Agents run in a ReAct-style harness with 4 tools (GoogleSearch, EdgarSearch, ParseHTML, RetrieveInformation) with live EDGAR access; graded by rubric-decomposed LLM-as-judge plus a contradiction check. 23 models evaluated; best (o3) 46.8% class-balanced accuracy; no model over 50%. Models are far cheaper/faster than the human expert reference (16.8 min, $25.66/question).

## Tasks
9 categories (Table 1/Table 3, n=537): Quantitative Retrieval 102, Qualitative Retrieval 97, Numerical Reasoning 83 (easy); Complex Retrieval 29, Adjustments 43 ("bridging GAAP and Non-GAAP Financial Metrics", e.g., Adjusted EBITDA), Beat or Miss 69 ("Comparison of forward management guidance versus actuals") (medium); Trends 33, Financial Modeling 47 ("Complex numerical reasoning calculations which require additional financial expertise", e.g., Amazon "M&A firepower... up to 2x GAAP EBITDA leverage"), Market Analysis 34 (hard). All are investor-side research over public filings; no spreadsheet artifacts (Appx D.1: tabular-data workflows explicitly deferred to future work).

## Eval method
LLM-as-judge with rubric-based assessment: GPT-4o auto-extracts per-question rubric checks from expert answers, author-reviewed; each key point checked separately; plus a "contradiction rubric" against the full expert answer. Metrics: class-balanced accuracy (per-category average; preferred) and naive accuracy. Splits: 50 public / 150 private-val / 337 private test (metrics in paper on all 537); val-test Pearson r=0.98.

## Data realism
Real, recent SEC filings via live EDGAR ("documents published no earlier than 2024 (after most training cutoffs)"); questions expert-authored and peer-reviewed by a second expert; answerable from open internet/public filings. Private test set held out against contamination.

## Agent scope
Multi-step single-agent tool use (ReAct-inspired; GoogleSearch/SerpAPI, EdgarSearch/SEC API metadata, ParseHTML to key-value store, RetrieveInformation for self-managed context). Turns range 3.5 (LLaMA 4 Maverick) to 12.1 (Claude 3.7 Sonnet); tool calls 1.7-24.8. Environment feedback with retryable-vs-agent error handling. Not multi-agent; no execution environment beyond retrieval.
