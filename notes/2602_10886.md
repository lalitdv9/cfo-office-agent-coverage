# The CLEF-2026 FinMMEval Lab: Multilingual and Multimodal Evaluation of Financial AI Systems

- arXiv ID: 2602.10886
- Authors: Zhuohan Xie, Rania Elbadry, Fan Zhang, Georgi Georgiev, Xueqing Peng, Lingfei Qian, Jimin Huang, Dimitar Dimitrov, Vanshikaa Jani, Yuyang Dai, Jiahui Geng, Yuxia Wang, Ivan Koychev, Veselin Stoyanov, Preslav Nakov (MBZUAI, U. Tokyo, Sofia U., The Fin AI, U. Arizona, INSAIT)
- Status: full-text fetched: Y (https://arxiv.org/html/2602.10886v1, complete lab overview)

## Summary
Shared-task lab overview (CLEF 2026): first multilingual + multimodal evaluation framework for financial LLMs, with three interconnected tasks across 7 languages. No corporate-finance/CFO-office track exists; inclusion is as ADJACENT BAND via Task 2's analyst-research task set.

## Tasks covered (task design)
- Task 1 Financial Exam QA: multiple-choice professional exam questions — CFA (600, English), CPA (300, Chinese: accounting, auditing, financial management, taxation, economic law, strategy), EFPA (230, Spanish), GRFinQA (268, Greek), BBF (500-1000, Hindi), SAHM (873, Arabic). Knowledge/reasoning QA, not workflow tasks.
- Task 2 PolyFiQA (multilingual financial QA): given English 10-K/10-Q excerpts + related multilingual news (en/zh/ja/es/el), answer expert-written questions. Two tiers, 172 QA each (344 total): Easy (factual/numerical trends, e.g., revenue growth, cash-flow irregularities) and Expert (multi-document analytical reasoning, e.g., investment strategies, capital allocation). Inter-annotator agreement >89%; MIT license. Reuses PolyFiQA datasets from MultiFinBen (arXiv 2506.14028).
- Task 3 Financial Decision Making: Buy/Hold/Sell daily trading decisions on BTC and TSLA in a live window; scored on Cumulative Return, Sharpe, Max Drawdown, volatility. Pure markets/trading (out of tree).

## Eval method
Task 1 accuracy; Task 2 ROUGE-1 primary + BLEURT + factual consistency; Task 3 quantitative trading metrics in a live, leakage-controlled window.

## Data realism
Task 2 uses real SEC filings + real multilingual news, expert-annotated. Task 1 uses exam-prep materials. Task 3 uses curated daily JSON contexts (single representative price, news syntheses, manually annotated momentum labels).

## Agent scope
Evaluation lab for LLMs/systems; Task 3 targets "LLM trading agents"; Tasks 1-2 are static QA. Not itself an agent system.

## Relevance to CFO-office taxonomy
- ADJ-1 (analyst/financial-research tasks): Task 2 PolyFiQA is a real, expert-built finance-analysis task set over public filings — qualifies the lab for the adjacent band per the standing scope ruling.
- CPA subset of Task 1 touches accounting/tax/audit knowledge but as certification-exam QA, not finance-function tasks; no core leaf coverage.
- Task 3 (trading) and most of Task 1 are outside the tree; do NOT score against core leaves.

## Key numbers
- 3 tasks, 7 languages (en, zh, ar, hi, el, ja, es); Task 2: 344 QA (172 Easy + 172 Expert), IAA >89%; Task 1 datasets: 600 CFA / 300 CPA / 230 EFPA / 268 GRFinQA / 500-1000 BBF / 873 SAHM.
