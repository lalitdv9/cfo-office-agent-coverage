# Large Language Models as Tax Attorneys: A Case Study in Legal Capabilities Emergence

- arXiv ID: 2306.07075
- Authors: John J. Nay, David Karamardian, Sarah B. Lawsky, Wenting Tao, Meghana Bhat, Raghav Jain, Aaron Travis Lee, Jonathan H. Choi, Jungo Kasai (Stanford, U. Michigan, U. Washington, USC, Northwestern Pritzker Law, SimPPL)
- Status: full-text fetched: Y (https://arxiv.org/html/2306.07075v1)

## Summary
Non-agentic LLM capability study on applying U.S. federal tax law. Auto-generates synthetic multiple-choice tax-law problems (facts, names, numbers randomized by Python code so questions cannot be in any training set), each with correct option, explanation, and citation to the governing CFR/U.S. Code section. Evaluates OpenAI models (through GPT-4) alone and with retrieval of legal text (from naive retrieval up to "gold truth" provision and a "mega run" with few-shot examples + most relevant text). Finds accuracy climbs with each model generation; GPT-4 with few-shot prompting and correct legal text performs at high accuracy but below expert tax-lawyer level.

## Tasks covered (task design)
Seven question types across tax law categories (CFR exam + U.S. Code exam), including: "Check the Box" entity classification (whether an entity is a per se corporation vs eligible to elect partnership/disregarded status — corporate structuring), Section 83 property-for-services problems (employee income inclusion and employer deduction), basis calculations, and Section 199A qualified business income deduction. Over 28,000 questions graded across experiments (GPT-4 used as grader; <1% grading error on audited subset).

## Eval method
Multiple-choice accuracy vs programmatically known ground truth; GPT-4-as-grader validated against manual grading. Experimental factors: model generation, retrieval condition (none → embeddings retrieval → gold-truth provision), few-shot prompting.

## Data realism
Synthetic law-school-exam-style problems (Lawsky-style generators) grounded in real statutes/regulations; not real corporate tax workpapers or filings.

## Agent scope
Non-agentic: single-LLM prompting + retrieval; no tool use, no multi-step agent loop. Include with this caveat — it is a foundational capability result for tax-function reasoning, not a tax-workflow system.

## Relevance to CFO-office taxonomy
- 4.4 Planning & controversy: check-the-box elections/entity classification are core corporate tax structuring questions.
- 4.2 Compliance & filings (secondary): statutory application (income inclusion, deductions, basis) underlies return positions.
- Mixed individual/business coverage: several question types concern individual taxpayers; corporate relevance comes from entity-classification and employer-deduction items.

## Key numbers
- "We assess the accuracy of responses generated by LLMs on thousands of tax law inquiries"; >28,000 questions across all experiments.
- Clear accuracy increase with each OpenAI model release on both CFR and U.S. Code exams (Fig. 4); best setup = GPT-4 + few-shot + gold-truth legal text; "not yet at expert tax lawyer levels."
