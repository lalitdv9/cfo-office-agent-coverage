# SheetAgent: Towards A Generalist Agent for Spreadsheet Reasoning and Manipulation via Large Language Models

- **ID:** arXiv:2403.03636 (v3, 3 Mar 2025; v1 6 Mar 2024) — verified from https://arxiv.org/abs/2403.03636 + https://arxiv.org/html/2403.03636v3 (full text)
- **Authors:** Yibin Chen, Yifu Yuan, Zeyu Zhang, Yan Zheng, Jinyi Liu, Fei Ni, Jianye Hao, Hangyu Mao, Fuzheng Zhang
- **Venue:** WWW 2025 (oral) per arXiv comments field
- **Status:** INCLUDE — category: cross-domain (E6 rule: general spreadsheet benchmark with a real finance-workbook task subset; survey analysis restricted to that subset)

## Summary
Proposes SheetRM, a 317-task / 1,625-subtask benchmark of long-horizon, reasoning-dependent spreadsheet manipulation (41 workbooks, 137 sheets, avg 300.82 rows), plus SheetAgent, an LLM agent with three modules (Planner = Python/openpyxl code generation with iterative reflection; Informer = task-specific SQL subviews; Retriever = code-example retrieval) that manipulates spreadsheets without human interaction.

## Finance-function subset (basis for cross-domain include)
Table 7 workbook inventory includes genuinely financial workbooks operated on by the agent:
- **PayrollSummary** — "the March 2014 employee salary sheet"
- **Deposit** — "a bank deposit journal"
- **QuarterlyEarnings** — "the company's earnings and financial reports for each quarter of 2020"
- **BudgetForecast** — "forecasts the company's budget allocations for the next fiscal year"
- **TaxFilingSummary** — "summarizes the company's tax filings for the past three years"
- **AdBudgetAllocation**, **SalesAndPurchase**, numerous sales-statistics workbooks (BookSales, DepartmentSales, QuartersSales, YearsSales...)
- Comparison dataset SCB: 221 GPT-4-generated tasks incl. "analyzing sales data, calculating financial metrics" (Sec on SCB).
Tasks on these files are generic spreadsheet operations (formatting, formula computation, conditional highlighting, chart building) rather than finance-process execution — hence partial (◐) leaf credit only.

## Leaf cells
- **2.5 ◐ (P)** — FP&A modeling/spreadsheets: agentic manipulation of budget-forecast, quarterly-earnings, and sales-analysis workbooks; operations are generic sheet manipulation, not model construction.
- **7.3 ◐ (P)** — payroll: salary-sheet workbook (PayrollSummary) manipulated as a task asset; no payroll-process logic.

## Eval method
Deterministic, model-free "procedure evaluation": per-task checklist of (Criterion, Sheet Index, Area, Properties) items automatically checked against the produced workbook; metrics Exec@1, Pass@1, SubPass@1 (Sec 2.3). No LLM judge.

## Data realism
Semi-real: spreadsheets sourced "from a public examination question bank" (real-life Excel exam files, anonymized); task instructions generated by GPT-4 under human validation (Sec 2.2). Corporate staff consulted on common operations.

## Agent scope
Single autonomous agent, three collaborating LLM modules (Planner/Informer/Retriever), code-action interface (Python + SQL), iterative reasoning + reflection, long-horizon multi-subtask execution. Not multi-agent orchestration, no enterprise-system integration.

## Key numbers (quoted)
- Abstract: "SheetAgent delivers 20--40% pass rate improvements on multiple benchmarks over baselines".
- Table 2 (SheetRM): SheetAgent (GPT-4) Pass@1 44.8 / SubPass@1 77.0 vs SheetCopilot (GPT-4) Pass@1 2.2 / SubPass@1 30.7; SheetAgent (GPT-o1) Pass@1 62.5.

## Survey use
Methods/background anchor for the spreadsheet-manipulation agent axis (2.5); evidence that even reasoning-augmented agents pass under half of long-horizon spreadsheet tasks. Analysis must cite only the finance-workbook subset for CFO-office claims.
