# FinanceQA: A Benchmark for Evaluating Financial Analysis Capabilities of Large Language Models

- arXiv ID: 2501.18062
- Authors: Spencer Mateega, Carlos Georgescu, Danny Tang (AfterQuery)
- Status: full-text fetched: Y (https://arxiv.org/html/2501.18062v1 — abstract, Sections 1-8, Table 1, Figure 7 fine-tuning table)
- Decision: INCLUDE, category = adjacent-band (ADJ) per human ruling on analyst-research benchmarks

## Summary
FinanceQA is a testing suite of on-the-job investment-analyst tasks (hedge fund / PE / IB style). Two pillars: (1) tactical questions grounded in a primary document (10-K), split into "basic" and "assumption-based" (incomplete-information) variants — e.g., hand-spreading diluted shares, adjusted EBITDA with one-time adjustments, operating-lease-aware debt; (2) conceptual questions (e.g., implied EBITDA margin from multiples). Annotators are former hedge fund/PE/IB professionals; answers graded as exact binary match by humans. SOTA models fail ~60% of tasks (best: o1 at ~48.7% total); assumption-based accuracy is <5% for all base models. Fine-tuning GPT-4o on 9,078 synthetic-augmented rows lifts total accuracy from 39.2% to 56.8%.

## Tasks covered
Three question types: Tactical-Basic, Tactical-Assumption, Conceptual. Exact question counts NOT stated in fetched text (fine-tuning set = 9,078 rows, separate from eval set). Tactical questions built on Costco's 10-K (per Limitations); context window = curated 10-K subset (financial statements, notes, MD&A).

## Eval method
Exact-match binary scoring, no partial credit; human annotators hand-evaluated responses ("The number 1 was given when answers correctly factored in the necessary assumptions and lines of reasoning an analyst would make on a job"). 4 models: GPT-4o, o1, Claude-3.5-Sonnet, Llama-3.3-70B-Instruct. Paired t-test (df=2), p=0.0342 for fine-tuning gains.

## Data realism
Real SEC filings (10-K, notably Costco; Microsoft/Dollar Tree examples), curated context; questions authored by practitioners without LLM aid, referencing Koller et al. Valuation and Holthausen & Zmijewski textbooks. Fine-tuning data partially synthetic (variations of human rows).

## Agent scope
None — single-turn prompted QA, no tools, no agent loop, no spreadsheet environment. Limitations explicitly note Excel financial modeling (DCF/LBO) "was not tested but is crucial for the practical adoption of LLMs in finance."
